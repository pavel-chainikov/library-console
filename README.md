# Library Console

Консольная программа для учёта книг в библиотеке на Java.

## Возможности

- показать все книги
- добавить книгу (с проверкой названия, автора и года)
- найти книги по автору (по части имени, без учёта регистра)
- выдать, вернуть и удалить книгу

## Как запустить

Открыть проект в IntelliJ IDEA и запустить класс Main.
